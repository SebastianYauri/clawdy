# Clawdy (ghost) · a Codex Pet

Clawdy is a free, open-source desktop buddy that shows how much of your Claude or Codex plan you've used and acts out what the agent is doing: https://github.com/SebastianYauri/clawdy

## Install

Copy this folder to `~/.codex/pets/clawdy-ghost/` (Windows: `%USERPROFILE%\.codex\pets\clawdy-ghost\`), then in Codex type `/pet` and pick **Clawdy (ghost)**.
